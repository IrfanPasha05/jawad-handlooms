# Jawad Handlooms Frontend

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

Use this directory as the frontend root on Netlify or Vercel. Build command: `npm run build`; output directory: `dist`.

The catalogue currently comes from `src/data.js`. Update it with the shop's real inventory and confirmed prices before customer launch.
